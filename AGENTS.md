# IA Solidaire

## Description du projet

Site vitrine professionnel pour IA Solidaire, cabinet de conseil spécialisé dans l'accompagnement des structures ESS et IAE dans l'adoption concrète, éthique et responsable de l'intelligence artificielle.

## Objectif du site

La V1 doit permettre aux visiteurs de comprendre le positionnement d'IA Solidaire, découvrir des cas d'usage adaptés à l'ESS, identifier les offres d'accompagnement, connaître le consultant et prendre contact facilement.

## Stack technique

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React pour les icônes

## Conventions de développement

- Construire en mobile first.
- Garder les composants simples, accessibles et réutilisables.
- Préférer les contenus statiques tant qu'aucune fonctionnalité dynamique n'est validée.
- Limiter les dépendances aux besoins réels.
- Ne pas ajouter de CMS, base de données, authentification ou paiement.
- Garder un style sobre, professionnel, humain et institutionnel.

## Règles de sécurité

- Ne supprimer aucun fichier sans validation explicite.
- Ne publier aucun contenu sans validation.
- Ne pas créer de fonctionnalité hors périmètre.
- Signaler les hypothèses et informations manquantes.
- Protéger les informations personnelles et éviter les données sensibles dans les exemples.

## Définition de terminé

- Toutes les pages V1 existent et sont navigables.
- Le site est responsive mobile, tablette et desktop.
- Le formulaire affiche les erreurs de validation et un message de confirmation.
- Les pages respectent une structure accessible.
- Le build Next.js réussit.
- Les limites V1 et pistes V2 sont documentées.

## Validation requise avant modification

- Ajout d'un service d'envoi email.
- Ajout d'un CMS, d'une base de données ou d'un espace membre.
- Modification majeure de la charte graphique.
- Publication sur GitHub, Vercel ou ajout d'un domaine.
- Remplacement des coordonnées ou ajout de données personnelles définitives.
